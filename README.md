# IPL Analysis Dashboard - Power BI

Interactive Power BI dashboard analyzing IPL matches, teams, players, and performance insights.

## Project Overview

This project analyzes IPL match and player data to understand team performance, match outcomes, player statistics, and seasonal trends through interactive Power BI visualizations.

## Tools Used

- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization

## Dashboard Preview

![IPL Dashboard 1](Dashboard_Image)

## Business Impact

The dashboard transforms IPL match and player data into actionable insights that can support team strategy, player evaluation, and performance planning.

- Player Selection: Identify consistent and high-performing players.
- Team Strategy: Compare team performance across seasons and opponents.
- Performance Tracking: Monitor player and team performance over time.
- Decision Making: Use data-driven insights to improve team planning.
- Trend Analysis: Identify patterns in wins, losses, and player performance.
